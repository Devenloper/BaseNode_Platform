### Принцип оркестрации команд

Система следует правилу строгой транзакционной изоляции:

> **Одна команда — один агрегат — одна транзакция.**

Command Handler обрабатывает только один агрегат в рамках одной транзакции Event Store.

Межконтекстная координация (Booking ↔ Unit, Charge ↔ Shift, Override ↔ Conflict и т.п.) осуществляется **исключительно через доменные события** и асинхронные проекции.

Прямой вызов агрегата одного контекста из другого контекста запрещён.

Данный принцип предотвращает:
- рост связности контекстов;
- превращение Application Layer в оркестрационный монолит;
- нарушение детерминизма Event Sourcing.
