### Граница ответственности FULL_MODE

Политика **FULL_MODE** является системной и применяется **исключительно в Application Layer**.

Domain Layer:
- не принимает решений о подтверждении внешних оплат;
- не интерпретирует статус PMS;
- не содержит логики допуска или запрета операций на основании FULL_MODE.

Application Layer:
- выполняет проверки FULL_MODE;
- инициирует события `PaymentVerificationRequired`;
- блокирует выполнение команд при отсутствии подтверждения оплаты.

Данное разделение является обязательным и предотвращает проникновение инфраструктурных и интеграционных зависимостей в доменную модель.
